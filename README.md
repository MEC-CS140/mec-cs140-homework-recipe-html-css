# CS140 Homework 2: Your Favorite Recipe

Example: [https://tinyurl.com/meccs140/hw2](https://tinyurl.com/meccs140/hw2)
_Share a recipe of your favorite dish!_

## Task
Create a page in HTML and CSS that describes in detail how to make a recipe of your choice so that someone could create the dish successfully. If you don’t have a favorite recipe, grab one from the internet.

## Requirements & Rubric (20 points each)
- At least 1 picture of the dish.
- List of at least 3 ingredients.
- Make a link to each ingredient on where to find it (e.g., Amazon, Walmart, Fresh Direct).
  - If it can’t be found, make a link to the store on Google Maps where you could find it.
- Step by step instructions (3 or more steps) on how to create the dish, in numbered order.
- Use CSS to change the background of the page so that it is no longer white.

## Extra Credit
- Make every ingredient URL change color when hovering (10 points).
